# Asset Library

Everything you generate or edit in Node Banana is saved as it is made — with or without a project — and collected in the **Assets view**. Nothing you make is lost just because you didn't remember to save it.

import { Callout } from 'nextra/components'

## Opening the Assets view

Press **`A`** on the canvas to open the Assets view.

## The Node Banana folder

Generated media and workflows are stored as files in the **Node Banana folder**, which defaults to your **Documents** folder. You can see its location, storage use, and cleanup options under **Settings → Library**, and move the folder somewhere else from there.

Projects you save by name live in that folder too. If you have existing project folders elsewhere, Node Banana finds them, offers them, and can move them into the Node Banana folder for you.

## Browsing assets

The Assets view is a grid of everything you've generated, with:

- **Filters** — Narrow the grid down to what you're looking for.
- **Favourites** — Mark assets you want to find again quickly.
- **Tags** — Organize assets with your own labels.
- **Trash and restore** — Removed assets go to the trash and can be restored.
- **Full-screen detail** — Open any asset to see it large, along with the **run that produced it**.
- **Jump to source** — From an asset's detail, jump to the workflow or project it came from.

<Callout type="info">
  Every asset remembers the run that made it — the model, settings, and inputs — so you can trace any image, video, audio clip, or 3D model back to the workflow that produced it.
</Callout>

## Tips

<Callout type="tip">
  Favourite your best generations as you work, then filter to favourites later when you're assembling final results. Because each asset links back to its run, you can reopen the exact workflow that produced a result and tweak it.
</Callout>
