# AI Quickstart

The Welcome screen provides templates and AI workflow creation.
To reopen it, select **Nb → Welcome screen**.

## Choose a template

1. Select **Templates**.
2. Choose a built-in template or a community workflow.
3. Load the workflow.
4. Check its prompts, media, providers, and models.
5. Run the workflow.

The app includes six built-in templates with sample images.

| Template | Purpose |
| --- | --- |
| Product Shot | Place a product in a new scene |
| Model + Product | Combine a model, product, and scene |
| Color Variations | Generate product colors from reference images |
| Background Swap | Place a subject in a new background |
| Style Transfer | Apply one image's style to another |
| Scene Composite | Combine elements from several scenes |

Community workflows come from Node Banana Pro's public workflow service.
They need an internet connection and the keys for their selected providers.
The app repository also includes sample media in `public/sample-images/` and workflows in `examples/`.

## Describe a workflow

**Prompt a workflow** requires a Gemini key in **Settings → Providers**.
The assistant uses the app's current Gemini text model.

1. Select **Prompt a workflow** on the Welcome screen.
2. Describe the inputs you have, the steps you want, and the required outputs.
3. Submit the description.
4. Check the generated nodes and noodles before you run them.

For example:

```text
Use a portrait image as a reference.
Create three background descriptions with an LLM.
Generate one portrait variation for each description.
Collect the results in an Output Gallery.
```

An LLM is a large language model that reads and generates text.
AI-generated workflows can need changes to model choices, prompts, or sockets.
You can edit those parts with the same controls as a manual workflow.

## AI chat and reverting changes

The current `develop` UI has no control to open the AI chat panel.
Use **Prompt a workflow** on the Welcome screen to create a workflow with AI.
The chat panel remains in the app, but its entry point is unavailable in this snapshot.

After an AI change, **Nb → Revert AI changes** restores the earlier workflow snapshot.
The command appears when an AI snapshot is available.

## Refine a generated workflow

If a workflow differs from your intent, include the missing step in a revised description.
If a model needs a key, add that provider in Settings or choose a configured model.
If sockets do not match, select a compatible model and reconnect the affected noodles.

Save a useful result with **Nb → Save project**.
See [Best practices](/guides/best-practices) for batch and reuse patterns.
