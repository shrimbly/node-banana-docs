# Models and Pricing

The tables describe the app's `develop` catalog checked on September 21, 2026.
Prices are the app's USD estimates, not a provider quote or a complete billing record.
A missing price means unknown, not free.

## Providers

Add keys in **Settings → Providers**.
A provider is the service that receives a generation request.
The same model family can have different settings and prices on different providers.

| Provider | Uses in Node Banana | Environment alternative |
| --- | --- | --- |
| Google Gemini | Images, Veo and Omni video, text, and workflow assistant | `GEMINI_API_KEY` |
| OpenAI | GPT Image generation and editing, and text | `OPENAI_API_KEY` |
| Anthropic | Claude text models | `ANTHROPIC_API_KEY` |
| Replicate | Discovered image, video, audio, and 3D models | `REPLICATE_API_KEY` |
| fal.ai | Discovered image, video, audio, and 3D models | `FAL_API_KEY` |
| Kie.ai | The image, video, and audio catalog listed below | `KIE_API_KEY` |
| WaveSpeed | Discovered media models, including image, video, and 3D | `WAVESPEED_API_KEY` |

ComfyUI uses a separate backend and key under **Settings → ComfyUI**.
See the [ComfyUI guide](/guides/comfyui) for Cloud, local, and remote workflows.

## Choose a model

1. Open **All models** on the action bar, or the model selector on a generation node.
2. Filter by provider and capability.
3. Select a model and check its input sockets.
4. Open the controls card to set its parameters.

A capability describes a task, such as text-to-image or image-to-video.
The browser also shows recently used models and provider-page links.
Model lists use a 48-hour cache.
Use the refresh control to clear cached lists and fetch them again.

Replicate, fal.ai, and WaveSpeed fetch catalogs from their services.
Their lists can change independently of an app release.
Some capability labels come from model descriptions, so check the actual model inputs.
For Replicate, an exact owner/model search can find entries outside the loaded list.

## OpenAI image models

| Model | ID | Cost representation in the app |
| --- | --- | --- |
| GPT Image 2.5 Sunburst | `gpt-image-2.5-sunburst` | Estimate from returned token usage |
| GPT Image 2.5 Flare | `gpt-image-2.5-flare` | Estimate from returned token usage |
| GPT Image 2 | `gpt-image-2` | Approximate $0.05 per run |
| GPT Image 1 | `gpt-image-1` | Approximate $0.05 per run |

GPT Image models support text-to-image and image editing.
Each direct OpenAI run requests one output.
The app accepts up to 16 reference images in PNG, JPEG, or WebP format.
Each reference must be smaller than 50 MB.
Load references through Image Input rather than supplying external image URLs.

| Setting | GPT Image 1 / 2 | GPT Image 2.5 |
| --- | --- | --- |
| Size | Auto, 1024×1024, 1024×1536, 1536×1024 | Auto, presets through 3840×2160 or 2160×3840, and valid custom sizes |
| Quality | Auto, Low, Medium, High | Also XHigh and Max |
| Background | Auto, Opaque, Transparent | Auto, Opaque, Transparent |
| Output format | Model default | PNG, JPEG, WebP |
| Compression | Model default | 0–100 for JPEG or WebP |

A GPT Image 2.5 custom dimension must be a positive multiple of 16 and no greater than 3840.
Its aspect ratio must stay between 1:3 and 3:1.
Its area must be 655,360–8,294,400 pixels.
The app describes sizes above 2560×1440 as experimental.
JPEG does not support a transparent background.

The GPT Image 2.5 estimate uses $5 per million text-input tokens and $8 per million image-input tokens.
It uses $30 per million image-output tokens.
Tokens are units the provider reports for text or image processing.
The estimate uses uncached rates and needs complete token counts.

| Veo 3.1 / Veo 3.1 I2V | Text / image-guided video | $0.40 per second |
| Veo 3.1 Fast / Veo 3.1 Fast I2V | Text / image-guided video | $0.15 per second |

I2V means image-to-video.
Veo offers 4-, 6-, or 8-second duration, 16:9 or 9:16 ratio, and 720p, 1080p, or 4k resolution.
Its image-to-video path uses the first reference image.
At the registry rate, eight seconds costs an estimated $3.20 for Veo 3.1 or $1.20 for Fast.

Omni offers automatic task selection, text-to-video, image-to-video, reference-to-video, edit, and extend tasks.
It uses the Gemini Interactions API.
Its resolution choices are 360p, 720p, 1080p, and 4k.
The model descriptions identify 1080p and 4k as upscaled outputs.
Desired duration becomes part of the prompt rather than a fixed duration parameter.

## Audio and 3D

Generate Audio uses model-specific settings for voice, format, and other controls.
Kie's ElevenLabs catalog covers speech, dialogue, and sound effects.
The Sound Effects model exposes a 0.5–22 second duration and a loop setting.
Replicate and fal.ai also expose audio models through discovery.
The app groups speech, music, and sound-effect categories under text-to-audio.

Generate 3D uses discovered text-to-3D or image-to-3D models from Replicate, fal.ai, and WaveSpeed.
Connect its 3D output to **3D Viewer** to inspect a GLB result.
You can capture a view as an image for another node.

## Cost tracking limits

The cost indicator opens **Workflow Costs** where supported.
The dialog separates Gemini estimates, external-provider links, and incurred cost.
Saved workflows retain the incurred total.

These figures are partial estimates.
The prediction code counts image and video generation nodes, but does not fully price batches, loops, text, audio, or 3D.
Per-second video rates also need the clip duration to produce a full estimate.
Some execution paths record provider costs, while others do not.
For example, the audio executor records fal pricing but does not add the static Kie audio rates.

A fallback can submit another provider request after the primary model fails.
Before a large batch or loop, check provider pricing and your account's billed usage.
