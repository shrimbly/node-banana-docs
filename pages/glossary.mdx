# Glossary

This table defines terms that appear across these guides.

| Term | Meaning | Learn more |
| --- | --- | --- |
| Agent | The Agent builds and edits workflows through Claude Code or Codex. | [Agent](/guides/agent) |
| API key | An API key authorizes requests to a provider account. | [Add provider keys](/installation#add-provider-keys) |
| backend | A backend is the service that runs a ComfyUI workflow. | [ComfyUI](/guides/comfyui) |
| base64 | Base64 encodes binary media as text and makes the workflow file larger. | [Project files and auto-save](/guides/assets#project-files-and-auto-save) |
| Blueprint | A Blueprint is a reusable subgraph supplied by the selected ComfyUI server. | [Use a Blueprint](/guides/comfyui#use-a-blueprint) |
| clip | A clip is one source video or audio file placed in an Edit Video timeline. | [Edit video](/guides/edit-video) |
| crossfade | A crossfade dissolves the picture and sound where two stacked clips overlap. | [Track and Stacked layouts](/guides/edit-video#track-and-stacked-layouts) |
| DMG | A DMG is a macOS disk image. | [macOS on Apple Silicon](/installation#macos-on-apple-silicon) |
| edit project | An edit project is a timeline saved on its own in the Edits folder. | [The Edit video view](/guides/edit-video#the-edit-video-view) |
| fallback model | A fallback model retries failed generation with another model and its own settings. | [Make execution deliberate](/guides/best-practices#make-execution-deliberate) |
| group | A group keeps related nodes together and moves them as a set. | [Groups and comments](/core-concepts#groups-and-comments) |
| JSON | JSON is a text format for structured data. | [Project files and auto-save](/guides/assets#project-files-and-auto-save) |
| node | A node performs one task, such as image generation or video trimming. | [Follow the data](/core-concepts#follow-the-data) |
| noodle | A noodle is a connection between two nodes. | [Follow the data](/core-concepts#follow-the-data) |
| provider | A provider is the service that receives a generation request. | [Providers](/guides/models-pricing#providers) |
| snapshot | A snapshot records the workflow as it was when that result was made. | [Assets and Storage](/guides/assets) |
| socket | A socket is an input or output point on a node. | [Follow the data](/core-concepts#follow-the-data) |
| workflow | A workflow is a set of nodes that pass data from one step to another. | [Follow the data](/core-concepts#follow-the-data) |
| ZIP | A ZIP is a compressed archive. | [Install the desktop app](/installation#install-the-desktop-app) |
