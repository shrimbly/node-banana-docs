# Changelog

These entries follow the app's release history.
Historical entries describe behavior at that release, including features that later releases replace.
The guides describe the checked `develop` snapshot, including Unreleased changes.

Dates come from the app's `CHANGELOG.md`, except 1.7.0 and 1.8.0, which use their published release notes.
The app records its initial release as 1.0.0 without a date.
It does not provide release entries or a date for the older docs' 0.x groupings.

- Gemini Omni models add video generation, editing, and extension through the Interactions API.
- The multi-select toolbar can change models across selected generators. ([#165](https://github.com/shrimbly/node-banana/pull/165))

- Node resizing changes width. Double-clicking a resize edge restores the default width. ([#149](https://github.com/shrimbly/node-banana/pull/149))
- Workflow tabs, the floating Nb menu, and an icon action bar replace the old top layout. ([#153](https://github.com/shrimbly/node-banana/pull/153))
- The navigator groups the minimap and view controls. ([#151](https://github.com/shrimbly/node-banana/pull/151))
- Videos play inline on hover.
- Missing inputs skip individual nodes instead of disabling Run.
- The multi-select toolbar adds spacing and Run controls.
- Recent generations moves to the top right.
- The text catalog adds current models and replacement notes for retired model IDs.
- The Welcome screen, onboarding, templates, and settings use split layouts.
- The Nb menu adds a Templates entry, and the Welcome screen updates its resource links.
- The app uses a new Nb icon.

### Fixed

- Workflow load and save discard temporary blob URLs that cannot survive another session. ([#168](https://github.com/shrimbly/node-banana/pull/168))

## 1.7.0 — 2026-07-07

### Added

- Output galleries use prepared thumbnails and collect multiple or looped video results.
- Stop cancels active video stitch, trim, and ease-curve encodes.
- Provider polling, downloads, and concurrent execution handle failures more reliably.

### Fixed

- Gallery removal deletes the selected item even when duplicates exist.
- Edits during auto-save no longer trigger a data-loss race.
- Workflow execution resumes more reliably after a pause noodle.
- Media handling bounds caches and handles oversized results.

## 1.0.0 — Initial Release

### Added

- The visual editor supports a canvas with draggable nodes.
- Image Input loads source images, and Prompt supplies text.
- Annotation provides a full-screen drawing editor.
- Nano Banana generates images through Gemini.
- LLM Generate creates text through Gemini and OpenAI.
- Output shows workflow results.
- Workflows save and load as JSON files.
- Socket validation checks compatible image and text noodles.
- Generation nodes accept multiple image references.
