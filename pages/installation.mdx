# Installation

import { Callout } from 'nextra/components'

These steps install the app from `develop`, including the unreleased features in these guides.
For the packaged Windows or macOS preview, see [Desktop app](/desktop).

## Install from source

Use Git, npm, and Node.js 22.12 or newer.
This Node version also supports the desktop tooling.

1. Clone the app repository and select `develop`.

```bash
git clone --branch develop https://github.com/shrimbly/node-banana.git
cd node-banana
```

2. Install the dependencies from the lockfile.

```bash
npm ci
```

3. Start the browser app.

```bash
npm run dev
```

4. Open `http://localhost:3000`.

The browser app uses the custom server in `server.js`.
If port 3000 is occupied, set `PORT` before the command.

```bash
# macOS or Linux
PORT=3001 npm run dev
```

```powershell
# PowerShell
$env:PORT = "3001"
npm run dev
```

## Add provider keys

1. Complete the first-run welcome step.
2. Enter a key for each provider you plan to use.
3. Choose your default models.
4. Select **Start tutorial**, or select **Skip** to open the editor.

You can change keys later in **Nb → Project settings → Providers**.
Throughout these guides, **Settings** means this Project settings dialog.

| Provider | Environment variable alternative |
| --- | --- |
| Google Gemini | `GEMINI_API_KEY` |
| OpenAI | `OPENAI_API_KEY` |
| Anthropic | `ANTHROPIC_API_KEY` |
| ComfyUI | `COMFY_API_KEY` for hosted models; `COMFY_CLOUD_API_KEY` for Cloud workflows |
| Replicate | `REPLICATE_API_KEY` |
| fal.ai | `FAL_API_KEY` |
| Kie.ai | `KIE_API_KEY` |
| WaveSpeed | `WAVESPEED_API_KEY` |

You only need keys for the providers you use.
The [Agent](/guides/ai-quickstart#start-with-agent) uses Claude Code or Codex account sign-in separately from these keys.
OpenAI supplies image and text models.
See [Models and pricing](/guides/models-pricing) for the complete provider list.

<Callout type="info">
  In browser mode, keys entered in Settings stay in browser storage and override environment keys.
  The desktop app encrypts stored credentials in its own profile.
</Callout>

### Use an environment file instead

1. Create `.env.local` in the app repository root.
2. Add only the variables for your selected providers.
3. Restart the app after you change the file.

```env filename=".env.local"
GEMINI_API_KEY=your_gemini_key
OPENAI_API_KEY=your_openai_key
ANTHROPIC_API_KEY=your_anthropic_key
COMFY_API_KEY=your_comfy_key
COMFY_CLOUD_API_KEY=your_comfy_key
REPLICATE_API_KEY=your_replicate_key
FAL_API_KEY=your_fal_key
KIE_API_KEY=your_kie_key
WAVESPEED_API_KEY=your_wavespeed_key
```

These values are placeholders.
Keep your real keys out of shared workflow notes and public repositories.

## Connect ComfyUI

Enter your Comfy account key in **Settings → Providers → ComfyUI**, then save the settings.
It covers hosted models and Comfy Cloud workflows.
Reopen **Settings → ComfyUI** and choose **Comfy Cloud**, **This computer**, or **Remote**.
Remote-server authentication stays with that backend.
The [ComfyUI guide](/guides/comfyui) covers keys, endpoints, and workflow imports.

## Create your project

1. Select **New project** on the Welcome screen.
2. Enter a project name and keep the default location, or choose a custom parent directory.
3. Save the project settings.
4. Follow [Your first workflow](/first-workflow).

New projects default to the shared Node Banana folder.
The app creates a project subfolder there, or inside your custom parent directory.
A custom directory must use an absolute path.
See [Assets and Storage](/guides/assets) to change the default folder or bring in existing projects.
For installation errors, see [Troubleshooting](/guides/troubleshooting).
