# Introduction

Node Banana builds workflows on a canvas.
A workflow is a set of nodes that pass data from one step to another.
A node performs one task, such as image generation or video trimming.
A noodle is a connection between two nodes.

## Follow the data

A socket is an input or output point on a node.
Socket types identify the data they accept, such as text, image, video, or audio.
You drag from an output socket to a compatible input socket.

For example, a Prompt node supplies text to a Generate Image node.
The generated image can feed an Annotation node, another model, or an Output node.
The app runs the steps in dependency order, so a node receives upstream results first.

## Choose your tools

| Work | Nodes and features |
| --- | --- |
| Prepare prompts | Prompt, Prompt Constructor, Array, and LLM Generate |
| Generate media | Generate Image, Generate Video, Generate Audio, and Generate 3D |
| Edit media | Annotation, Remove Background, Image Resize, and video processing nodes |
| Control branches | Router, Switch, Conditional Switch, and loop noodles |
| Collect results | Output, Output Gallery, Image Compare, and 3D Viewer |
| Reuse ComfyUI workflows | ComfyUI App, Blueprints, and saved nodes |

The [node reference](/nodes) explains each input, output, and setting.

## Run locally and choose providers

You can run the app in a browser or use the [desktop preview](/desktop).
Your workflows are JSON files that store the canvas and node settings.
JSON is a text format for structured data.
Media can live beside the workflow file or inside it.

An API key authorizes requests to a provider account.
Add keys in **Nb → Project settings → Providers** for the models you use.
Generation sends the relevant prompts and media to the selected provider.
Local files and a local editor do not make remote generation offline.

The [model guide](/guides/models-pricing) lists providers and the app's cost estimates.
ComfyUI has separate [backend settings](/guides/comfyui).
A backend is the service that runs a ComfyUI workflow.
