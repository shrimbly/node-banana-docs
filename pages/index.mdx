Node Banana is a visual workflow editor for AI images, video, audio, text, and 3D models.
You connect nodes to load media, build prompts, call models, and process results.

## How it works

A workflow is a set of nodes on a canvas.
Each node does one task, such as generating an image or trimming a video.
A socket is an input or output point on a node.
A noodle connects an output socket on one node to an input socket on another.
The app runs each node after its inputs are ready.
See [Follow the data](/core-concepts#follow-the-data) for an example.
