# Settings

Open **Nb → Project settings** to access all seven tabs.
Save changes with the dialog's save control.
These guides call this dialog **Settings**.

## Settings tabs

| Tab | What you set | Learn more |
| --- | --- | --- |
| Project | Project name, location, Save automatically, and Embed images as [base64](/glossary) | [Project files and auto-save](/guides/assets#project-files-and-auto-save) |
| Storage | Shared Node Banana folder, existing projects, moves, and library cleanup | [Choose the Node Banana folder](/guides/assets#choose-the-node-banana-folder) |
| Providers | Keys for the eight model providers | [Providers](/guides/models-pricing#providers) |
| ComfyUI | Backend, authentication, job timeout, and seed behavior | [Choose a backend](/guides/comfyui#choose-a-backend) |
| Node defaults | New image/video models, LLM settings, and Max parallel calls | [Change the result](/first-workflow#change-the-result) |
| Canvas | Pan, zoom, and selection gestures | [Canvas gestures](#canvas-gestures) |
| Noodles | Line style, thickness, faded opacity, gradient, and loading pulse | [Appearance](/core-concepts#appearance) |

## Canvas gestures

In **Canvas**, pan choices are Space + Drag, Middle Mouse, and Always On.
Zoom choices are Alt + Scroll, Ctrl + Scroll, and Scroll.
Selection choices are Click, Alt + Drag, and Shift + Drag.
The initial settings use Space + Drag, Alt + Scroll, and Click.
On macOS, trackpad gestures also pan the canvas.
