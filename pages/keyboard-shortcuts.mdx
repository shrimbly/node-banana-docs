# Keyboard Shortcuts

import { Callout } from 'nextra/components'

Use `Cmd` on macOS and `Ctrl` on Windows or Linux.
Most canvas shortcuts do not act while you type in an input field.
Save also works during text editing outside the Agent window.
A noodle is a connection between two nodes.

## Canvas

| Shortcut or gesture | Action |
| --- | --- |
| `Cmd/Ctrl + Enter` | Run workflow or resume a pause |
| `Alt/Option + Enter` | Run selected nodes |
| `Cmd/Ctrl + S` | Save, or open first-save setup |
| `A` | Show or hide Assets |
| `Cmd/Ctrl + C` | Copy selected nodes |
| `Cmd/Ctrl + V` | Paste nodes, an image, or text |
| `Cmd/Ctrl + Z` | Undo |
| `Cmd/Ctrl + Shift + Z` | Redo |
| `?` | Show keyboard shortcuts |
| `Shift + P` | Add Prompt |
| `Shift + I` | Add Image Input |
| `Shift + G` | Add Generate Image |
| `Shift + V` | Add Generate Video |
| `Shift + D` | Add Generate 3D |
| `Shift + O` | Add Output |
| `Shift + L` | Add LLM Generate |
| `Shift + A` | Add Annotation |
| `Shift + T` | Add Generate Audio |
| `Shift + Y` | Add Video Input |
| `Shift + R` | Add Router |
| `Shift + C` | Add ComfyUI App |
| `V` with two or more selected nodes | Stack vertically |
| `G` with two or more selected nodes | Arrange as a grid |
| Hold `H` + drag | Hook noodles into a bundle |
| Scroll, with your configured modifier | Zoom in or out |
| Trackpad on macOS | Pan |
| `Delete` / `Backspace` | Delete selected nodes |

<Callout type="info">
The app's shortcut dialog currently labels `Shift + R` as Array.
The canvas handler creates a Router.
</Callout>

Use the multi-select toolbar for horizontal stacking.
You can also save through **Nb → Save project** or the save button.
Pan, zoom, and selection gestures are under [Canvas gestures](/settings#canvas-gestures).

## Assets

These shortcuts apply in Assets, outside text fields.

| Shortcut | Action |
| --- | --- |
| `←` / `→` / `↑` / `↓` | Move between assets |
| `Enter` | Open the asset |
| `←` / `→` with an asset open | Previous or next asset |
| `Space` | Select the asset |
| `Cmd/Ctrl + A` | Select all loaded assets |
| `Delete` | Trash selected assets; in Trash or Missing files, open the deletion or removal confirmation |
| `Cmd/Ctrl + Z` | Undo the last asset action |
| `Cmd/Ctrl + C` with an asset open | Copy its prompt |
| `F` with an asset open | Full screen |
| `Esc` | Close, clear selection, or return to the canvas |

## Output Gallery viewer

| Shortcut | Action |
| --- | --- |
| `←` / `→` | Previous or next result |
| `Enter` | Add to graph |
| `D` | Download |
