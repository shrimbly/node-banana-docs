# Nodes Reference

A node performs one workflow step.
This reference covers all 28 node types on the checked `develop` snapshot.
A noodle is a connection between compatible input and output sockets.

## Common controls

Double-click or right-click empty canvas space to search for a node.
You can also drag a noodle onto empty space to create a compatible node.

A media node has a preview card, history or scrub controls, and a collapsible controls card.
Drag a resize edge to change width.
Double-click the edge to restore the default width.
Videos play inline on hover, and media nodes provide download buttons.

Generation nodes keep result history and provide a Fallback tab for another model.
A failed primary model can trigger an automatic retry with the fallback settings.
Generation notifications report progress or errors.
The Recent generations panel shows results across the canvas.

If a node has no usable input, execution skips it.
For optional inputs, pauses, groups, and partial runs, see [Core concepts](/core-concepts#workflow-execution).

## Image Input

Load a source image or receive one from another node.

**Inputs:** A local file or a reference image noodle.

**Outputs:** One image.

### Settings

| Setting | Effect |
| --- | --- |
| Image | PNG, JPEG, or WebP, up to 10 MB. |
| Optional | Allows an empty input to skip its dependent branch. |

### Tips

- Reuse one image output across several generators.
- Use the download button to save the current image.

## Audio Input

Load or preview an audio file.

**Inputs:** A local audio file or an audio noodle.

**Outputs:** One audio result.

### Settings

| Setting | Effect |
| --- | --- |
| Audio | Upload or drop an audio file, up to 50 MB. |
| Optional | Allows an empty input to skip its dependent branch. |

### Tips

- Preview the audio before you connect it to a video model or Video Stitch.

## Video Input

Load a video for generation or processing.

**Inputs:** A local video file or a video noodle.

**Outputs:** One video.

### Settings

| Setting | Effect |
| --- | --- |
| Video | MP4, WebM, or MOV, up to 200 MB. |
| Optional | Allows an empty input to skip its dependent branch. |

### Tips

- Use the preview and scrubber to inspect the clip.
- Connect Frame Grab to extract a reference image.

## Annotation

Draw instructions or marks over an image.

**Inputs:** A connected image or an uploaded PNG, JPEG, or WebP file, up to 10 MB.

**Outputs:** The image with your annotations.

### Settings

| Setting | Effect |
| --- | --- |
| Editor tools | Select, rectangle, circle, arrow, freehand, and text. |
| Color and width | Eight colors and three stroke widths. |

### Tips

- Connect the result to Generate Image as a visual reference.
- Without annotations, the source image passes through.

## Prompt

Provide text for another node.

**Inputs:** Typed text or a text noodle.

**Outputs:** Prompt text.

### Settings

| Setting | Effect |
| --- | --- |
| Prompt | Text in the node or its larger editor. |
| Variable name | A name that Prompt Constructor can reference. |
| Optional | Allows an empty prompt to skip its dependent branch. |

### Tips

- Use a variable name such as subject for reusable prompt templates.
- A connected text input updates the prompt.

## Array

Split text into items for separate branches or repeated generation.

**Inputs:** Text from an upstream Prompt, LLM Generate, or another text node.

**Outputs:** Text as the full JSON array, an item assigned to each noodle, or sequential batch items.

### Settings

| Setting | Effect |
| --- | --- |
| Split mode | Delimiter, Newline, or Regex. Regex means a regular expression, which is a text-matching pattern. |
| Delimiter | The initial delimiter is *. |
| Trim spaces / Drop empty | Clean parsed items. Both start enabled. |
| Batch | Runs each item through a supported generator. Initially disabled. |
| Item list | Click an item to expand or collapse its full text. |
| Make Prompts | With Batch off, creates a wired Prompt node for each item. |

### Tips

- Batch supports Generate Image, Generate Video, Generate Audio, and LLM Generate.
- Use Make Prompts for separate branches that you can edit.
- New noodles cycle through the items and show **Array n** labels. Batch noodles show **All n**.
- Clicking an item expands it; it does not choose the next noodle's item.

## Prompt Constructor

Build one prompt from named text values.

**Inputs:** Text from connected Prompt nodes or other text sources.

**Outputs:** The resolved prompt.

### Settings

| Setting | Effect |
| --- | --- |
| Template | Use @name to insert a named variable. |
| Preview | Shows the resolved text and supports copying from the editor. |

### Tips

- Name a Prompt variable, connect it, then use its @name in the template.
- Check unresolved variables before generation.

## Generate Image

Generate or edit an image with the selected model.

**Inputs:** Text and reference images, as supported by the selected model.

**Outputs:** One generated image.

### Settings

| Setting | Effect |
| --- | --- |
| Provider and model | Choose a model from the model browser. |
| Aspect ratio and resolution | Available values depend on the model. |
| Search | Google Search on direct Nano Banana Pro and Nano Banana 2. Image Search on Nano Banana 2. |
| Model settings | Open the controls card for settings supplied by the selected model. |
| Fallback | An alternative model and its own settings for an automatic retry. |

### Tips

- Use the [model tables](/guides/models-pricing) to check provider-specific settings.
- Use the node history to compare earlier results.

## Generate Video

Generate, edit, or extend video with a selected model.

**Inputs:** Text, images, video, or audio through the model-specific sockets.

**Outputs:** One video.

### Settings

| Setting | Effect |
| --- | --- |
| Provider and model | Select a video model to expose its sockets. |
| Model settings | Duration, aspect ratio, resolution, and other fields depend on the model. |
| Fallback | An alternative model and settings for a retry. |

### Tips

- For Seedance 2 I2V, use First/Last Frame or Reference Images, not both modes together.
- Seedance reference limits are nine images, three videos, and three audio inputs.

## Generate Audio

Generate speech, sound effects, or other audio from a selected model.

**Inputs:** Text by default, with extra sockets where the model defines them.

**Outputs:** One audio result.

### Settings

| Setting | Effect |
| --- | --- |
| Provider and model | Choose an audio model from Kie.ai, fal.ai, Replicate, or another discovered provider. |
| Model settings | Voice, format, and other fields depend on the model. |
| Fallback | An alternative model and settings for a retry. |

### Tips

- Use Array batch mode for a list of speech prompts.
- Send the result to Output or Video Stitch.

## LLM Generate

Use a large language model (LLM) to generate text or describe an image.

**Inputs:** Text and optional images.

**Outputs:** Generated text.

### Settings

| Setting | Effect |
| --- | --- |
| Provider and model | Google, OpenAI, or Anthropic. See the [current catalog](/guides/models-pricing#text-models). |
| Temperature | Controls variation. Range 0–1 for Anthropic, or 0–2 for Google and OpenAI. |
| Max tokens | Limits output length from 256 to 16,384 tokens. Tokens are units of text used by the model. |
| Fallback | An alternative model and settings for a retry. |

### Tips

- Send generated lists to Array for batch prompts.
- A retired saved model ID triggers a replacement note.

## Split Grid

Split an image into cells and create a node set for each cell.

**Inputs:** One source image.

**Outputs:** Cell images supplied to the generated per-cell node sets.

### Settings

| Setting | Effect |
| --- | --- |
| Rows and columns | 1–16 on each axis. The initial grid is 2 rows × 3 columns. |
| Slice lines | Drag boundaries to create unequal cells. |
| Open cell editor | Edit the reusable node template for each cell. The initial template contains Image Input. |
| Layout | Grid, vertical, or horizontal placement for the generated node sets. |
| Shared Router | Template terminal outputs can feed one shared downstream Router. |
| Split rows × columns now | Creates the cell groups and fills their base Image Input nodes. |

### Tips

- Build a processing chain once in the cell editor, which supports every node type.
- With unchanged dimensions and template, another split preserves cell edits. A changed layout or template can rebuild the node sets.

## Output

Show and save a final media result.

**Inputs:** Image, video, or audio.

**Outputs:** No output sockets.

### Settings

| Setting | Effect |
| --- | --- |
| Output filename | Custom name for the saved or downloaded result. |

### Tips

- With a project directory, execution saves output files in outputs/.
- Video nodes already play inline, so Output is optional for preview.

## Output Gallery

Collect image and video results in one place.

**Inputs:** Images and videos from connected nodes.

**Outputs:** No output sockets.

### Settings

| Setting | Effect |
| --- | --- |
| Gallery | Shows collected results, with the newest first. |
| Extract | Creates input nodes from gallery items. |
| Item actions | Open the shared viewer, add to graph, download, remove, or open in Assets. |

### Tips

- Connect batch generators to collect their results.
- Use Extract to reuse gallery media elsewhere on the canvas.
- In the viewer, press `Enter` for Add to graph or `D` for Download.
- Use the arrow keys to browse results. Add to graph reuses one item; Extract handles the gallery.

## Image Compare

Compare two images with a movable divider.

**Inputs:** The first two images connected to its image input.

**Outputs:** No output sockets.

### Settings

| Setting | Effect |
| --- | --- |
| Divider | Drag the slider to reveal each image. |

### Tips

- Connect an original image and its edited result to compare them.

## Video Stitch

Join several video clips into one video.

**Inputs:** At least two ordered video clips and optional audio.

**Outputs:** One combined video.

### Settings

| Setting | Effect |
| --- | --- |
| Clip order | Reorder the clips in the filmstrip. |
| Loop | Repeat the sequence 1×, 2×, or 3×. The default is 1×. |

### Tips

- Check clip order before you run the node.
- Connect audio for a soundtrack. The encoder also preserves embedded clip audio.

## Ease Curve

Change a video's playback speed over time.

**Inputs:** Video and, optionally, an ease curve from another node.

**Outputs:** Processed video and reusable ease-curve data.

### Settings

| Setting | Effect |
| --- | --- |
| Preset or custom curve | Choose a preset or edit the Bézier curve. A Bézier curve uses control points to shape a smooth path. |
| Output duration | 0.1–30 seconds. The default is 1.5 seconds. |
| Incoming curve | Inherits the upstream curve, preset, and duration. |

### Tips

- Connect the curve output to another Ease Curve node to share timing.
- Use Stop to cancel an active encode.

## Video Trim

Keep a selected part of a video.

**Inputs:** One video.

**Outputs:** The trimmed video, including its audio.

### Settings

| Setting | Effect |
| --- | --- |
| Start | First retained time in seconds. The default is 0. |
| End | Last retained time in seconds. It must exceed Start and 0. |

### Tips

- Use the range preview before encoding.
- Trim clips before you send them to Video Stitch.

## Frame Grab

Extract the first or last frame of a video.

**Inputs:** One video.

**Outputs:** A full-resolution PNG image.

### Settings

| Setting | Effect |
| --- | --- |
| Frame | First or Last. The default is First. |

### Tips

- Use the last frame as the first-frame reference for another video generation.

## Remove Background

Remove an image background in the browser.

**Inputs:** One image.

**Outputs:** The image with its background removed.

### Settings

| Setting | Effect |
| --- | --- |
| Model | Fast, Balanced, or Quality. The default is Balanced. |

### Tips

- Start with Balanced. Use Fast or Quality to change the speed and quality tradeoff.

## Image Resize

Resize an image before another processing step.

**Inputs:** One image.

**Outputs:** One resized image.

### Settings

| Setting | Effect |
| --- | --- |
| Mode | Exact dimensions, Max edge, or Scale %. |
| Dimensions | Positive pixel dimensions. Scale accepts 1–400%. |
| Exact fit | Contain, Cover, or Stretch. |
| Format | Keep, PNG, JPEG, or WebP. |
| Quality | 0.1–1 for JPEG and WebP. The default is 0.9. |

### Tips

- Use Max edge to preserve proportions. The longest output edge cannot exceed 8192 pixels.
- The initial settings are Exact, 128×128, Contain, and PNG.

## GIF Encoder

Combine image frames into an animated GIF.

**Inputs:** At least two ordered image frames.

**Outputs:** An animated GIF through an image socket.

### Settings

| Setting | Effect |
| --- | --- |
| Frame order | Reorder the filmstrip before encoding. |
| FPS | Frames per second, from 1 to 30. The default is 8. |
| Colors | Palette size from 2 to 256. The default is 128. |
| Dithering | Adds a pattern to approximate missing colors. Initially disabled. |
| Target size | Optional size tuning. The default target is 128 KiB. |

### Tips

- Resize frames consistently first. The encoder caps the longest edge at 1024 pixels.
- Target-size tuning can reduce colors, dimensions, and frame count. It does not guarantee the target size.

## Router

Pass inputs onward without generation or processing.

**Inputs:** Image, text, video, audio, 3D, or ease-curve data.

**Outputs:** The same data types.

### Settings

| Setting | Effect |
| --- | --- |
| Typed lanes | The initial Any socket expands into lanes for connected data types. |

### Tips

- Use a Router to share a source across branches.
- Use a noodle bundle when you only want to change how the lines look.

## Switch

Enable or disable named output branches.

**Inputs:** One dynamically typed input.

**Outputs:** The same data through enabled outputs.

### Settings

| Setting | Effect |
| --- | --- |
| Outputs | Add and rename output branches. |
| Enabled | Toggle each output. The initial Output 1 is enabled. |

### Tips

- Disable a branch without deleting its noodles.

## Conditional Switch

Route text to every rule that matches it.

**Inputs:** Text.

**Outputs:** Text through matching rule outputs, or Fallback when no rule matches.

### Settings

| Setting | Effect |
| --- | --- |
| Rule type | Exact, Contains, Starts with, or Ends with. |
| Rule values | Comma-separated alternatives. Matching ignores case and trims text. |
| Evaluation pause | Pause to inspect the rule result. |

### Tips

- Several rules can match the same text.
- Connect Fallback to handle unmatched text.

## Generate 3D

Generate a 3D model from text or an image.

**Inputs:** Text or images through model-specific sockets.

**Outputs:** A 3D model.

### Settings

| Setting | Effect |
| --- | --- |
| Provider and model | Select a compatible Replicate, fal.ai, or WaveSpeed model. |
| Model settings | Fields depend on the selected model. |
| Fallback | An alternative model and settings for a retry. |

### Tips

- Connect the 3D output to 3D Viewer to inspect it and capture an image.
- Generate 3D does not use Array batch mode.

## 3D Viewer

Inspect a GLB file and capture a view as an image.

**Inputs:** A 3D model noodle or a local .glb file up to 100 MB.

**Outputs:** A captured PNG image.

### Settings

| Setting | Effect |
| --- | --- |
| View | Orbit the model to choose the camera angle. |
| Auto-rotate | Rotate the model automatically. |
| Capture | Capture the current view as an image. |

### Tips

- GLB is a binary file format for 3D scenes.
- Before you use the image output in another node, select Capture.

## ComfyUI App

Run an imported ComfyUI workflow as one node.

**Inputs:** Typed sockets selected from the imported workflow. An empty node has no sockets.

**Outputs:** Selected workflow results, including image, text, video, audio, or 3D data.

### Settings

| Setting | Effect |
| --- | --- |
| Workflow | Attach an editor save, API export, Blueprint, or saved node. |
| Exposed controls | Choose inputs, settings, and outputs in the import or edit dialog. |
| Backend | Set Comfy Cloud, This computer, or Remote in Settings → ComfyUI. |

### Tips

- Use [saved nodes](/guides/comfyui#save-and-reuse-a-configured-node) to reuse an attached workflow and its values.
- The [ComfyUI guide](/guides/comfyui) covers setup, formats, previews, and the curve editor.
