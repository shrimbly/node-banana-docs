# Your First Workflow

This example sends a text prompt to an image model and shows the result.
You need a provider key from [installation](/installation).

## Choose how to start

| Welcome screen entry | What it opens |
| --- | --- |
| New project | Project name and storage settings |
| Open project | Known projects, including projects in other folders |
| [Templates](/guides/templates) | Built-in templates and community workflows |
| [Start with Agent](/guides/agent) | Claude Code or Codex setup and an Agent conversation |
| Bring in your projects, when no projects are known | Search for existing projects and choose whether to move them |

To reopen this screen, select **Nb → Welcome screen**.
The first-run setup includes provider keys, model defaults, and an interactive tutorial.
During first-run setup, **Start tutorial** offers a guided demonstration with simulated execution.
The tutorial uses simulated execution, so its demonstration does not submit real generation requests.
To bring in projects from an older installation, see [Bring in existing projects](/guides/assets#bring-in-existing-projects).

For this example, create a new project.

1. Select **New project** on the Welcome screen.
2. Enter a project name and keep the default location, or choose a custom parent directory.
3. Save the project settings.

New projects default to the shared Node Banana folder.
The app creates a project subfolder there, or inside your custom parent directory.
A custom directory must use an absolute path.
See [Choose the Node Banana folder](/guides/assets#choose-the-node-banana-folder) to change the default folder.

## Add three nodes

1. Press `Shift + P` to add a Prompt node.
2. Enter this prompt.

```text
A ceramic teapot on a wooden table beside a window.
Use soft daylight and a plain background.
```

3. Press `Shift + G` to add a Generate Image node.
4. Open its controls card and select a model for your configured provider.
5. Add an **Output** node from the floating action bar.

You can also double-click empty canvas space and search for a node by name.
The [node reference](/nodes) explains model settings and media inputs.

## Add noodles

A noodle connects an output socket to an input socket.

1. Drag the Prompt text output to the Generate Image text input.
2. Drag the Generate Image image output to the Output image input.

```text
Prompt → Generate Image → Output
```

Socket labels appear on hover, selection, and drag.
The media card shows the result, and the controls card holds the node settings.
You can open or collapse those controls from their summary row.

## Run the workflow

1. Check the selected provider, model, prompt, and resolution.
2. Select **Run** on the floating action bar, or press `Cmd/Ctrl + Enter`.
3. Wait for the Generate Image node to finish.
4. Check the image in the generation node and the Output node.

A status notification reports generation progress or errors.
If a node has no usable input, the app skips that node.
See [workflow execution](/core-concepts#workflow-execution) for partial runs and pauses.

## Change the result

1. Edit the prompt.
2. Run the workflow again.
3. Use the generation node's history controls to compare results.

The **Recent generations** panel shows the current tab's recent results.
Open [Assets](/guides/assets) for the full library and generation-time workflow snapshots.
Media nodes also provide download buttons.
For a new default model, use **Settings → Node defaults**.
Defaults apply to new nodes, so existing nodes keep their own settings.

## Save and reopen

1. Press `Cmd/Ctrl + S`, or select **Nb → Save project**.
2. To reopen a workflow, select **Nb → Open project…**.
3. Choose the saved workflow in the browser.

Keep the project directory and its media subfolders together.
Auto-save starts after the first save.
See [Project files and auto-save](/guides/assets#project-files-and-auto-save).
